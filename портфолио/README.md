# Портфолио СКОиПТ — Приложение

## Что это
Одностраничное приложение портфолио студента в эстетике тёмной академии. Работает в любом браузере, может быть установлено как мобильное/десктопное приложение (PWA).

## Файлы проекта
- `index.html` — основное приложение
- `manifest.json` — манифест PWA (установка как приложение)
- `service-worker.js` — работа офлайн
- `icon-192.svg`, `icon-512.svg` — иконки приложения

## Как использовать

### 1. Просто открыть
Дважды щелкните по `index.html` — откроется в браузере. Все данные сохраняются в браузере (localStorage).

### 2. Установить как приложение (PWA)
**В Chrome / Edge / Яндекс Браузере:**
1. Откройте `index.html`
2. В адресной строке появится иконка установки (или кнопка "Установить приложение" внизу экрана)
3. Нажмите "Установить" — приложение появится на рабочем столе

**На iPhone (Safari):**
1. Откройте `index.html` в Safari
2. Нажмите "Поделиться" → "На экран «Домой»"

**На Android:**
1. Откройте в Chrome
3. Меню (три точки) → "Добавить на главный экран"

Все данные хранятся **только в вашем браузере**. Если очистите кэш браузера — данные удалятся. Используйте кнопку "Экспорт данных (JSON)" для резервной копии.
